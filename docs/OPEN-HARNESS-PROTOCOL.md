# Cross-harness ordinary protocol and changes

Author: Ajnas N B. October 1, 2026.

Primary agents: Codex, OpenCode and OpenHands. Additional compatibility agents:
Goose and Aider. “All open harnesses” is interpreted as a representative named
set, not an exhaustive claim about every agent project.

The frozen three-template schedule is inherited from ordinary-v1. Each primary
agent has 24 shuffled rows: original/rename/formatting, three fresh unchanged
controls, and a neutral/misleading pair per template. Requests do not state the
exact security rule or announce private expected cases. Source/docstrings and
native permission instructions remain.

The model is the same verified Azure Sol deployment for all five agents.
Real credentials stay in the controller, outside cloned source. File/tool policy
is restricted and recorded. Native system prompts differ; completion counts
are not a ranking.

Initial failures are retained. Continuations are separately labeled and
registered before their calls. They are not secretly substituted into a
completed 24-run primary benchmark. No cap was increased by raising the
overall $1.50 allowance.

The final reported usage is $1.2543425, plus $0.0621575 of explicit uncertain
request reservations. These are public pricing estimates/guards, not a
subscription billing guarantee.

## Native integration adjustments

Codex's official CLI binary uses the cloned tag's model catalog, adapting the
deployment alias and direct-MCP tool presentation. Noninteractive approval
metadata is truthful and limited to the four brokered project tools. One
no-edit result arising from native read-only instructions is retained.

OpenCode is the verified official release. Provider configuration uses the
actual OpenAI Responses implementation against the relay; only the exact
deployment and project MCP tools are enabled. Background title requests still
occur and are included in accounting.

OpenHands is the actual SDK Agent/Conversation loop, with the four project
tools and its normal completion signal. The SDK may return plain JSON rather
than SSE; both formats are parsed. Token-price warnings in its own logger are
not accepted as study accounting.

Goose is the official native release, forced to the Responses endpoint with a
three-original-task MCP smoke. Aider uses its pinned older text-editing runtime,
Sol's text-only Chat Completions support and actual unittest execution in a
throwaway writable copy. Aider is not presented as sharing the exact MCP/tool
policy or full schedule.

## Measurement

Completion requires a changed executable AST, preserved public argument list,
successful test invocation and completed trajectory. Behavioral correctness
is independently reported. An unchanged safe file or a process exit code 0 is
not sufficient.

The controller scores exact runtime tags, ordinary outputs, prohibited record
returns and unknown evidence separately. Incorrect code, crashes, unreadable
worker paths and timeouts do not become automatically safe or automatically
leaking. All failed setup and interrupted candidates are retained.

Output predictions are a different research task. Each known-positive function
gets one original and one Boolean-mutated question. The author's saved wrong
answers, today's model answers and runtime equivalence are separate evidence.
Auxiliary title responses are filtered by their actual request role, never by
matching the expected answer. Malformed answers are retained as incorrect.

## What was not run

No full Codex Rust workspace build/test, full OpenCode workspace suite,
unrestricted native shell benchmark, new ERP ordinary agent batch or exhaustive
all-agent comparison was performed. Selected Codex SDK/OpenHands component
tests and actual release/SDK agent runs are recorded precisely.
