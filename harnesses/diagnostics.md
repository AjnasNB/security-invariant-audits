# Integration diagnostics retained separately from measured outcomes

October 1, 2026. These are setup facts, not discovered invoice vulnerabilities.

## Delta

The earlier verbose-public-test/context-rollover issue and old model preset are
documented in `docs/delta-issue-explained.md`. Only the research integration was
corrected. Delta's product source and user profile were not changed.

## Codex

The first direct proxy expected plain function tools. Codex 0.159.3 advertised
namespaced/deferred tools and the proxy refused before paid inference. A
research-specific model catalog now maps the verified Azure alias to the
GPT-6.1 Sol metadata, exposes direct MCP tools and disables built-in shell,
patch and deferred-code execution surfaces. This is a restricted integration,
not stock Codex behavior. The actual CLI still owns conversation/tool execution.

Some initial SDK integration tests were copied without their expected Git trust
context and were blocked by the CLI's trust guard. Their runtime errors do not
establish broken model reasoning or data exposure. The focused subprocess test
suite is run separately; the broader mock-CLI suite remains reported according
to its actual result, not silently labelled as passing.

## OpenHands

The actual SDK Agent/Conversation is used with the three study custom tools.
The selected security tests initially had five import errors because the
agent-server persistence namespace was absent from the SDK-only installation.
The unchanged upstream persistence models can be supplied read-only for a
bounded rerun. This is test-environment completion, not a production bug fix.

LiteLLM does not recognize the Azure deployment alias for its cost lookup.
Provider raw usage remains recorded by the trusted proxy. No zero/missing
LiteLLM cost is represented as free inference.

## Claude Code

Claude Code 2.1.118 is a commercial binary; its MIT Python SDK is separate.
The initial proxy mishandled the query-bearing Foundry Messages path. Then the
deployed Azure endpoint rejected optional `context_management` input. The
compatibility proxy strips exactly that field, recording it separately, while
preserving model identity, prompts and tools. The original source is not edited.

The sixth measured Claude Code trajectory stopped at the host controller's
conservative $5 planning-reservation cap before an edit. The guard reserves
worst-case input/output charges and is not the actual Azure bill. That attempt
is retained as budget-stopped, not a successful refactor, security violation,
or a reason to bypass the cap by rerunning it as if no stop occurred.
